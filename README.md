# ¡Palabras Mágicas! (600 Core Spanish Words)

Interactive, kid-friendly Spanish vocabulary web app built around the 80/20 Pareto core of 603 high-frequency conversational Spanish words and phrases.

## Features

- **Flashcards:** 3D flip cards with touch swipe gestures, highlighted context sentences, dual-speed Spanish audio (Liebre / Tortuga), and Auto-Audio mode.
- **Quiz:** 10-question rounds (Spanish to English, English to Spanish, and Listening Challenge) with error review.
- **Completa la Frase:** Fill-in-the-blank sentence practice in context.
- **Deletrear:** Interactive Spanish spelling game with blanked hints and an on-screen accent tray.
- **Speed Match:** Timed pair-matching game with personal best records.
- **Mochila de Repaso:** Automatic spaced review deck for missed words.
- **Printable Study Sheets:** Print-ready study sheets and cut-out flashcards.
