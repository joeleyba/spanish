# Spanish 600

Mobile-first, 80/20 conversational Spanish vocabulary trainer built around the 603 highest-frequency words and phrases spoken in everyday Spanish.

## Features

- **Conversational Learning Path:** 25 topic-based units across 5 real-world modules (First Conversations, Sentence Glue & Time, Power Verbs, Describing & Numbers, People/School/World) instead of A-to-Z alphabetical order.
- **Smart Flashcards:** Clean Anki-style study flow (`Spanish -> English` default with 1-tap `English -> Spanish` active recall toggle), collapsible example sentences, touch swipe gestures, and dual-speed Spanish audio (`Listen` / `Slow`).
- **5 Practice Modes:** Flashcards, 10-question Multiple-Choice Quiz (ES->EN, EN->ES, Listening), Fill-in-the-Blank Context sentences, Interactive Spelling with accent tray, and timed Speed Match with personal best records.
- **Review Queue:** Automatically collects missed and "Still Learning" words for focused review.
- **Mobile-First & Dark Mode:** Thumb-friendly bottom navigation on phones, Light/Dark theme toggle, printable study sheets & cut-out flashcards, and JSON progress backup.
